# Add models from a provider

After creating the provider and provider key, create models for that provider.

<Steps>

<Step>
Open the provider detail page.
</Step>

<Step>
In the **Models** section, choose **Batch Create**.

</Step>

<Step>
Select the provider key.
</Step>

<Step>
Search the model catalog by model name, slug, type, or capability.
</Step>

<Step>
Use filters such as **All models**, **New only**, or **Existing only**.

</Step>

<Step>
Select one or more models.
</Step>

<Step>
Click **Create Selected Models**.

</Step>

</Steps>

![Add Models from catalog](/gifs/providers-add-models.gif)




Batch Create imports metadata such as type, capabilities, context, and pricing when available. If a model name collides with an existing record, create it with the same upstream slug and a different Odock model name. See [Add a variant model](/docs/models-and-mcp/models/add-variant-model).
