# Tutorials

These tutorials assume you can access `/{organisation}/plugins/flow` and have a virtual API key for testing.

## Tutorials

- [Build your first flow](/docs/plugins/flow-studio/tutorials/build-your-first-flow)
- [Activate a flow on one API key](/docs/plugins/flow-studio/tutorials/activate-a-key-flow)
- [Debug a flow run](/docs/plugins/flow-studio/tutorials/debug-a-flow-run)

## Before You Start

You need:

- **ORG_ADMIN** access to build and activate an organisation-wide flow (managers and users can view the library read-only)
- ownership or management rights over the API key you plan to test with, to activate a **key flow**
- a virtual API key with access to the model or MCP server your test request will call

For the concepts behind these steps, start with [Flow Studio](/docs/plugins/flow-studio).
