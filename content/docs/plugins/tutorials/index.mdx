## Before You Start

You need:

- ORG_ADMIN access to activate, configure, and place plugins for the organisation
- at least one virtual API key, to test a plugin's effect or to bind a key-level plugin

For flow-based automation instead of a fixed plugin, see the [Flow Studio tutorials](/docs/plugins/flow-studio/tutorials).
